# 🧠 What I actually like building

I enjoy going a little deeper than just making the thing *work*.

A lot of my projects eventually lead me into things like:

```cpp
std::vector<interest> current_obsessions {
    algorithms,
    data_structures,
    bitboards,
    chess_engines,
    systems_programming,
    linux_tooling,
    tui_interfaces,
    fpga_design
};
```

My favorite language is **C++**, especially when the problem involves algorithms,
data structures, performance or low-level design.

At the same time, I use **JavaScript / TypeScript** when the goal is actually
shipping something to the web instead of reinventing HTTP in C++.

Usually.

# ♟️ Chess arc

Chess programming has somehow become one of my largest side quests.

I'm interested in:

- bitboards
- move generation
- attack generation
- magic bitboards
- search
- chess engines
- tactical pattern detection
- large-scale game analysis
- chess analytics

### ♟️ [`chess-engine`](https://github.com/Nerver-zip/chess-engine)

A chess engine written in **C++**, built as a playground for understanding the
mechanics behind chess engines instead of treating them as black boxes.

```text
position
   │
   ├── board representation
   ├── attacks
   ├── move generation
   ├── legality
   └── search
        │
        └── rabbit hole ↓
```

I'm also exploring systems for turning raw chess analysis into useful
information about a player's **patterns, strengths and weaknesses**.
